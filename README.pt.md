# Ícones Tabler para a interface do SiYuan

Este Plugin de Ícones para [SiYuan (aka SiYuan Note)](https://siyuan-en.b3log.org/) pretende aplicar o conjunto de ícones [Tabler](https://tabler.io/icons) como elementos da interface do programa.

Criei este plugin baseado no [modelo oficial](https://github.com/siyuan-note/icon-sample) e usando a versão mais recente do [.js dos Litheness Icons](https://github.com/siyuan-note/siyuan/blob/master/app/appearance/icons/litheness/icon.js) como ponto de referência a quais ícones são necessários especificamente.

Minha motivação é de uso pessoal: já tenho os Tabler Icons como meu conjunto padrão para usar em documentos no lugar dos emojis predefinidos, então quis combinar este conjunto de ícones com o [tema Savor](https://github.com/royc01/notion-theme) para alinhar nesse sentido a interface do programa com os meus documentos.

Imenso agradecimento a [Paweł Kuna](https://github.com/tabler/tabler-icons) por criar um conjunto de ícones tão bonito, agradável, versátil, grátis e de código aberto. :Tabler Icons/heart-filled:
