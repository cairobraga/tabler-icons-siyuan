# Iconos Tabler para la interfaz de SiYuan

Este Plugin de Iconos para [SiYuan (aka SiYuan Note)](https://siyuan-en.b3log.org/) tiene la intención de aplicar el [conjunto Tabler Icons](https://tabler.io/icons) como iconos de la interfaz del software.

He creado este plugin basado en la [plantilla oficial](https://github.com/siyuan-note/icon-sample) y utilizando la versión más reciente del [.js de Litheness Icons](https://github.com/siyuan-note/siyuan/blob/master/app/appearance/icons/litheness/icon.js) como punto de referencia a cuales iconos se necesitan específicamente.

Estoy motivado por el uso personal: ya uso los Iconos Tabler como mis simbolos de elección para documentos en lugar de los emojis predeterminados, así que quería combinar este conjunto de iconos con el [tema Savor](https://github.com/royc01/notion-theme) para alinear mi interfaz del software con mis documentos en ese sentido.

Enorme gracias a [Paweł Kuna](https://github.com/tabler/tabler-icons) por crear un conjunto de iconos tan agradable, hermoso, versátil, libre y de código abierto. :Tabler Icons/heart-filled:

Si utiliza y disfruta de este plugin, por favor considere donar al proyecto original de Tabler Icons y su creador a través de [OpenCollective](https://opencollective.com/tabler), [PayPal](https://paypal.me/codecalm) o [GitHub Sponsors](https://github.com/sponsors/codecalm).
